# Depop Gallery Zoom

## Purpose

Adds a full-screen viewer to Depop listings with high-resolution images, zoom, pan, wraparound navigation, thumbnails, keyboard shortcuts, and touch gestures.

## Supported pages

- `https://www.depop.com/*`
- `https://depop.com/*`

## Testing notes
